# Petagotchi-Lite

Basit bir Python tabanlı sanal evcil hayvan uygulaması.

## Ne yapar?
- Evcil hayvanın durumu gösterilir.
- Kullanıcı etkileşimi olarak sadece iki seçenek vardır:
  - Arkadaş bul (evcil hayvan için arkadaş arar/oluşturur)
  - Çıkış (uygulamadan çıkar)

## Gereksinimler
- Python 3.8 veya üzeri

## Kurulum
1. Depoyu klonlayın:
   git clone https://github.com/ctrl-alt-del-2010-developer/Petagotchi-Lite-.git
   cd Petagotchi-Lite-
2. Sanal ortam oluşturup etkinleştirin (önerilir):
   python -m venv venv
   source venv/bin/activate  # Linux / macOS
   venv\Scripts\activate     # Windows
3. Bağımlılıklar varsa yükleyin:
   pip install -r requirements.txt
   (requirements.txt yoksa bu adımı atlayın)

## Çalıştırma
- Uygulamayı başlatmak için:
  python main.py

## Kullanım
- Uygulama açılınca menü görünür:
  1) Arkadaş bul — Evcil hayvan için bir arkadaş bulma/oluşturma işlemi yapar.
  2) Çıkış — Uygulamadan çıkar.
- Menüde seçim yapmak için ilgili numarayı veya belirtilen tuşu girin.
